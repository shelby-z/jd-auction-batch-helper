京东批量上拍 · 资料助手（Windows 64 位）

一、启动
1. 将整个压缩包解压到一个可写文件夹，例如桌面或 D 盘。
2. 双击带图标的“资料助手.exe”，浏览器会自动打开工具，不会出现黑色命令窗口。
3. 请不要在压缩包内直接运行，也不要单独移动启动文件。

已包含运行环境，无需安装 Python 或 Codex。使用本机浏览器操作。普通资料读取和打包可离线使用；AI 功能需要网络和你自己的 API 设置。

二、使用
1. 选择政府或海关模板，将一个项目的资料 ZIP、文件夹或文件拖入页面。
2. 如需 AI，在“AI 设置”中填入自己的 API 地址、模型名和 Key，保存并测试连接。
3. 读取资料后检查拟上拍和已排除的数量；可展开查看排除原因和原表位置。
4. 在“项目统一设置”填写类目、联系人、保证金、加价幅度等。保证金可设置比例和最低阈值；各标的也能单独修改。
5. 照片按原表素材编号、文件夹及文件名归集。每次只显示当前拍品的部分照片，可展开并设主图；导出时自动重命名。
6. 完成核对后生成并下载 ZIP，再到京东/京麦后台导入、配置剩余内容并提交。本工具不会替你提交上拍。
7. 起拍价按各标的原始表格金额保留。保证金和加价幅度的计算条件在“项目统一设置”填写一次，分别使用每个标的自己的起拍价计算；单独修改过的保证金、加价幅度保留，点击“恢复沿用统一设置”可重新按规则计算。
8. 长任务会弹出处理进度，显示当前事项、百分比、已用时间及本阶段预计剩余秒数。尚无足够进度时显示“正在估算”；不会假装已完成。刷新后可恢复当前后台任务；关闭服务或重启电脑会中断任务。
9. 加价幅度有独立的最低阈值及取整开关。默认开启四舍五入、取最接近的 5 的倍数；优先级为最低阈值＞取 5 的倍数＞四舍五入。取 5 的倍数时最低 5 元，仅四舍五入时最低 1 元，都关闭时最低 0.01 元；自定义阈值更高时按阈值。240 元起拍、1% 加价时为 5 元；12.1 元取整 5 后为 10 元。

三、资料与设置
初始包不包含任何已有项目、照片、鉴定资料、历史记录、API 配置或本机资料链接，只附带清空示例内容的政府/海关模板。
你使用后产生的资料和 API 设置保存在本文件夹的 data 中，导出包在 outputs 中，运行日志在 logs 中。下次双击启动可继续；移动工具时应移动整个文件夹。
使用后的文件夹会包含你自己的资料与 API Key。如要再次转发给他人，请发送原始压缩包。
普通资料识别时，提取的文档文字、文件名和目录等会发送给你配置的服务商；不逐张识图，不发送原始照片。扫描 PDF 的本机文字识别可按需开启。“上拍后复核”单独开启图片复核时，会向配置的图片模型发送待比对照片。

四、启动异常
首次启动可能需要数秒。启动窗口会显示准备进度，完成后自动打开网页；也可点击“打开操作网页”。
启动窗口不必一直保持打开。启动失败时会显示中文原因，可点击“重新启动”或“查看运行记录”。
如果默认浏览器没有自动打开，复制窗口中的 http://127.0.0.1 开头的网址，粘贴到 Chrome 或 Edge 的地址栏。
默认使用本机 4184 起的可用端口；同一文件夹重复启动会复用自己的服务，不连接其他副本的项目。
网页错误旁有“复制错误信息”，可将中文错误和编号发给维护人员。运行记录在 logs 中。电脑重启后重新双击资料助手即可。

五、AI 读取
支持提供聊天补全兼容接口的服务商。只发送当前文件的文字片段；长文件自动拆小，不发送原始照片。
表格先逐工作表识别列的含义，再从原表读取全部分组与价格，去掉空白格式列对上下文的占用。
模型提示上下文不足或输出截断时会继续拆小；对不支持强制 JSON 或系统消息的兼容模型自动调整请求格式。
读取后可展开“逐文件处理结果”。失败、空结果、未提取到文字都会明确提示，其他已完成片段会保存。失败后重试会沿用已完成片段。
不同模型的准确率仍有差异；没有原文证据的字段不会自动填入。扫描 PDF 可开启本机文字识别，普通图片只读取名称、目录和规格。

六、上拍后复核
选择保留原始资料的项目，进入“上拍后复核”，上传京东专场导出的 ZIP，输入密码后点击读取。支持传统 ZIP 加密；不支持的加密方式会明确提示。密码不保存在项目中。
选择京东专场及原始表格对应的专场范围。原表未注明专场时，需明确选择“原表未标专场的全部拍品”，不要混用不同专场。
程序重新读取原始表格分组，检查漏项、多项、错场、起拍价、保证金和双方都有的其他字段。同拍品因订单重复产生的行只计一次，重复信息冲突会提示。
保证金以项目比例/阈值、统一金额及单独设置作为依据；导出表或原材料没有提供的字段列为“未核实”。原表未明确分组、读取失败、无法唯一匹配时不会判定通过。
图片复核默认关闭。开启后按拍品编号读取京东公开图片，逐张与当前对应文件夹中的原图比较，并检查主图顺序。像素完全相同先在本机确认，其他照片由支持图片的模型辅助判断；可以单独填写图片模型名，API 地址和 Key 沿用现有设置。无法访问、模型不支持、判断不清楚都列为未核实，不代表图片正确。
图片较多时需要较长时间及 API 费用。复核结束后可以下载完整 HTML 记录，展开每个拍品查看预期值、京东值及依据，或打开京东商品链接。复核只读取公开资料，不代为提交或修改京东拍品。

适用环境：Windows 10/11 64 位。其他系统不适用本包。已在当前 Windows 环境验证独立解压启动，未在同事电脑上验证。
模板依据：20260202 模板包内的政府/海关瀚英模板。京东后台模板变化时需要更新适配。
第三方运行库的版本见“依赖版本.txt”，许可证保留在 runtime 对应目录。
